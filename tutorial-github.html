Como colocar o projeto no GitHub

Projeto: Portal do Técnico em Informática – Escola Maria Barbosa Leite

Este tutorial mostra como enviar a pasta Projetos para o GitHub e como enviar novas atualizações depois.

1. Instalar o Git

  1. Acesse git-scm.com/download/win.
  2. Baixe e instale o Git para Windows.
  3. Mantenha as opções padrão durante a instalação.
  4. Feche e abra novamente o VS Code.

Abra o terminal com Ctrl + J e confirme a instalação:

git --version

2. Criar uma conta no GitHub

  1. Acesse github.com.
  2. Clique em Sign up ou Criar conta.
  3. Informe seu e-mail, senha e nome de usuário.
  4. Confirme o e-mail caso o GitHub solicite.

3. Criar o repositório

  1. Entre no GitHub.
  2. Clique em New ou no ícone + no canto superior direito.
  3. Escolha New repository.
  4. Digite um nome, por exemplo portal-informatica.
  5. Escolha Public ou Private.
  6. Não marque Add a README file neste primeiro momento.
  7. Clique em Create repository.

4. Abrir a pasta correta no VS Code

  1. Abra o VS Code.
  2. Clique em Arquivo e depois em Abrir Pasta.
  3. Selecione C:\xampp\htdocs\Projetos.
  4. Abra o terminal com Ctrl + J.
O terminal deve estar dentro da pasta do projeto antes de executar os comandos.

5. Enviar o projeto pela primeira vez

Execute os comandos abaixo, um por vez:

git init
git add .
git commit -m "Primeira publicação do projeto"
git branch -M main

Na página criada no GitHub, copie o endereço HTTPS. Será parecido com:

https://github.com/SEU-USUARIO/portal-informatica.git

Substitua SEU-USUARIO pelo nome da sua conta e execute:

git remote add origin https://github.com/SEU-USUARIO/portal-informatica.git
git push -u origin main
  • git init prepara o controle de versões.
  • git add . seleciona todos os arquivos.
  • git commit salva uma versão no computador.
  • git remote add origin conecta ao repositório do GitHub.
  • git push envia os arquivos para a internet.
Na primeira autenticação, o navegador pode pedir autorização. Entre na mesma conta usada para criar o repositório.

6. Conferir os arquivos

  1. Atualize a página do repositório no GitHub.
  2. Verifique se os arquivos HTML, CSS e JavaScript apareceram.
  3. Abra o index.html para conferir o projeto.
  4. Se o commit e o nome da conta aparecerem, o envio foi concluído.

7. Enviar novas alterações

Depois de alterar e salvar um arquivo no VS Code, execute:

git add .
git commit -m "Atualização do site"
git push

Outra forma usando os botões do VS Code

  1. Abra Controle de Código-fonte.
  2. Confira os arquivos alterados.
  3. Clique no + ao lado de Alterações.
  4. Escreva uma mensagem curta no campo superior.
  5. Clique em Confirmar.
  6. Clique em Sincronizar alterações.

Antes de enviar

Não envie senhas, chaves, arquivos .env, dados pessoais ou informações secretas.

Arquivos PHP podem ser enviados, mas verifique se não existe senha ou chave dentro do código.

Problemas comuns

O Git não foi reconhecido

Feche todo o VS Code, abra-o novamente e teste git --version.

Erro de autenticação

Autorize o Git Credential Manager pelo navegador. Não digite a senha do GitHub na barra de endereço.

O push foi rejeitado

Execute:

git pull --rebase origin main
git push

Já existe um repositório Git na pasta

Não execute git init novamente. Execute apenas os comandos de adição, commit e push.

Alteração não apareceu no GitHub

Confirme que o arquivo foi salvo, adicionado com git add ., confirmado com git commit e enviado com git push.

Checklist final

  • □ Conta criada no GitHub.
  • □ Git instalado no computador.
  • □ Repositório criado no GitHub.
  • □ Pasta correta aberta no VS Code.
  • □ Arquivos adicionados e enviados.
  • □ Projeto aparece no repositório.
  • □ Nenhuma senha ou chave foi enviada.
