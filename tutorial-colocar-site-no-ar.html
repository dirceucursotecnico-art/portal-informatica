Como colocar o site no ar

Projeto: Portal do Técnico em Informática – Maria Barbosa Leite
Objetivos: publicar o site na internet e configurar PHP e MySQL

Opções de publicação

Hospedagem escolar ou local: usa o computador com XAMPP e o endereço localhost. Funciona somente dentro da rede do equipamento ou da escola.
Hospedagem profissional: usa um provedor de internet, permite acesso público e domínio próprio.

Parte 1 – Preparar o site localmente

  1. Confirme que todos os arquivos estão dentro de C:\xampp\htdocs\Projetos.
  2. Abra o XAMPP.
  3. Inicie Apache e MySQL.
  4. Acesse http://localhost/Projetos/index.html.
  5. Teste todas as páginas, menus, imagens, links e o formulário Fale Conosco.
  6. Em todas as páginas HTML, mantenha:
<meta charset="UTF-8">

Parte 2 – Preparar os arquivos

Arquivos necessários

  • Arquivos HTML.
  • Arquivos CSS.
  • Arquivos JavaScript, caso existam.
  • Arquivos PHP, como contato.php.
  • Imagens utilizadas pelo site.

Verificar os caminhos

Prefira barras normais em links e arquivos:

<link rel="stylesheet" href="style.css">
<img src="imagens/robo.png">
<a href="noticias/noticias.html">Notícias</a>
Não utilize caminhos absolutos do computador, como C:\xampp\htdocs\Projetos, em links HTML ou CSS.

Parte 3 – Publicar com servidor local acessível na rede

Esse método permite testar em celulares ou computadores da mesma rede.

  1. Abra o XAMPP e confirme que Apache e MySQL estão iniciados.
  2. Abra o Prompt de Comando.
  3. Digite:
ipconfig
  1. Copie o endereço IPv4, por exemplo: 192.168.1.25.
  2. No celular ou outro computador da mesma rede, acesse:
http://192.168.1.25/Projetos/index.html

Se não conseguir acessar

  1. Abra Painel de Controle do Windows.
  2. Acesse Firewall do Windows Defender.
  3. Abra Configurações avançadas.
  4. Permita o Apache na rede privada.
  5. Confirme que todos os dispositivos estão no mesmo Wi-Fi.
A rede pode desconectar o computador da hospedagem local. Além disso, este método não oferece domínio público ou certificado HTTPS automático.

Parte 4 – Publicar em hospedagem profissional

  1. Escolha uma hospedagem que ofereça PHP e MySQL.
  2. Registre um domínio, caso deseje um endereço próprio.
  3. Acesse o painel da hospedagem, como cPanel ou hPanel.
  4. Abra o Gerenciador de Arquivos.
  5. Entre na pasta pública do site. Normalmente é chamada public_html, www ou htdocs.
  6. Envie os arquivos do projeto para essa pasta.

Estrutura correta

public_html/
├── index.html
├── style.css
├── fale-conosco.html
├── contato.css
├── contato.php
├── imagens/
└── demais páginas e arquivos

Parte 5 – Criar o banco no servidor

  1. No painel da hospedagem, abra MySQL / phpMyAdmin.
  2. Crie o banco de dados, por exemplo: portal_mbl.
  3. Crie um usuário específico para o banco.
  4. Defina uma senha forte.
  5. Conceda ao usuário todas as permissões no banco.
  6. Atualize os dados de conexão no arquivo PHP.

Exemplo de conexão segura

$servidor = 'localhost';
$usuario = 'usuario_da_hospedagem';
$senha = 'senha_forte_do_banco';
$banco = 'portal_mbl';

$mysqli = new mysqli($servidor, $usuario, $senha, $banco);

if ($mysqli->connect_error) {
    exit('Erro na conexão com o banco de dados.');
}

$mysqli->set_charset('utf8mb4');
No código publicado, nunca use dados reais em vídeos, prints ou materiais públicos. Troque sempre os dados do servidor pelo que foi fornecido pela hospedagem.

Parte 6 – Criar a tabela no servidor

Entre no phpMyAdmin da hospedagem, selecione o banco e execute:

CREATE TABLE contatos (
    id INT UNSIGNED NOT NULL AUTO_INCREMENT,
    nome VARCHAR(100) NOT NULL,
    email VARCHAR(150) NOT NULL,
    telefone VARCHAR(20) NOT NULL,
    mensagem VARCHAR(1000) NOT NULL,
    data_envio DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    PRIMARY KEY (id)
) ENGINE=InnoDB
DEFAULT CHARSET=utf8mb4
COLLATE=utf8mb4_unicode_ci;

Parte 7 – Configurar domínio e HTTPS

  1. No painel da hospedagem, adicione o domínio.
  2. Configure os DNS fornecidos pelo provedor.
  3. Ative o certificado SSL/HTTPS.
  4. Aguarde a ativação do DNS e do certificado.
  5. Acesse o site usando https://seudominio.com.br.

Parte 8 – Testar no servidor público

  1. Abra o site pelo endereço público.
  2. Teste todas as páginas internas.
  3. Teste o Fale Conosco em celular e computador.
  4. Envie uma mensagem de teste.
  5. Abra o phpMyAdmin e confira a nova linha em contatos.
  6. Confirme acentuação, imagens e links.

Checklist final

  • □ Apache/PHP estão funcionando.
  • □ MySQL está disponível.
  • □ Banco de dados e usuário foram criados.
  • □ Dados de conexão estão corretos.
  • □ Tabela contatos existe.
  • □ Os arquivos estão na pasta pública.
  • □ Links usam barras normais.
  • □ Todas as páginas têm UTF-8.
  • □ PHP usa utf8mb4.
  • □ O domínio redireciona para HTTPS.
  • □ Formulário foi enviado e salvo no banco.
  • □ Site foi testado em celular e computador.

Problemas comuns

Erro 404 – Página não encontrada

Confirme o nome da pasta, a primeira letra maiúscula ou minúscula e os nomes dos arquivos.

Erro de conexão ao banco

Confirme servidor, usuário, senha, nome do banco e permissão do usuário.

Dados sem acentuação

Use UTF-8 no HTML, utf8mb4 no PHP, banco e tabela com codificação utf8mb4_unicode_ci.

Página PHP mostra o código-fonte

A hospedagem não está interpretando PHP ou o arquivo não foi enviado como .php. A função PHP deve ser fornecida pelo servidor.

Mensagens não são gravadas

Verifique permissões do banco, existência da tabela, campos do formulário e nome dos campos no $_POST.
