Como usar o Supabase gratuitamente

Projeto: Portal do Técnico em Informática – Maria Barbosa Leite

O Supabase oferece PostgreSQL, autenticação, armazenamento e APIs. Ele pode substituir o MySQL local do formulário Fale Conosco, permitindo que o site publicado na Vercel envie mensagens para um banco na nuvem.

1. Criar uma conta no Supabase

  1. Acesse supabase.com.
  2. Clique em Start your project ou Sign in.
  3. Entre com GitHub, Google ou outro método disponível.
  4. Clique em New project.
  5. Escolha ou crie uma organização.
  6. Digite o nome do projeto, por exemplo portal-informatica.
  7. Crie uma senha forte para o banco e guarde-a em local seguro.
  8. Escolha uma região próxima do público que usará o site.
  9. Clique em Create project e aguarde a preparação.
Limites e regiões do plano gratuito podem mudar. Consulte a página oficial de preços antes de publicar um projeto que precise de disponibilidade garantida.

2. Criar a tabela de contatos

Dentro do projeto, abra SQL Editor, clique em New query e execute:

create table public.contatos (
  id bigint generated always as identity primary key,
  created_at timestamptz not null default now(),
  nome varchar(100) not null,
  email varchar(150) not null,
  telefone varchar(20) not null,
  mensagem varchar(1000) not null
);

Depois, crie regras de segurança no mesmo SQL Editor:

alter table public.contatos enable row level security;

create policy "Permitir envio público"
on public.contatos
for insert
to anon
with check (char_length(trim(nome)) > 0
  and char_length(trim(email)) > 0
  and char_length(trim(telefone)) > 0
  and char_length(trim(mensagem)) > 0);

create policy "Somente usuário autenticado pode ler"
on public.contatos
for select
to authenticated
using (true);

grant insert on public.contatos to anon;
grant usage, select on sequence public.contatos_id_seq to anon;
Não conceda permissões de leitura ao usuário público (anon). Assim, visitantes poderão enviar mensagens, mas não visualizar registros dos demais usuários.

3. Copiar as credenciais públicas

  1. Abra Project Settings.
  2. Acesse API ou a seção de conexão mostrada pelo painel.
  3. Copie a Project URL.
  4. Copie a chave pública identificada como Publishable key, ou a chave anon em painéis que ainda usam a versão anterior.
A chave pública pode ficar no JavaScript do navegador, mas ela não deve substituir as regras de segurança. Nunca publique a chave secreta service_role, senhas ou dados administrativos no código do site.

4. Conectar o formulário HTML

O Supabase fornece uma biblioteca JavaScript. Inclua no fale-conosco.html, antes do fechamento de </body>:

<script src="https://cdn.jsdelivr.net/npm/@supabase/supabase-js@2"></script>
<script src="supabase-contato.js"></script>

Altere o formulário para não enviar ao arquivo PHP:

<form id="contato-form" class="contato-form">

Crie o arquivo supabase-contato.js com:

const SUPABASE_URL = 'COLAR_AQUI_A_PROJECT_URL';
const SUPABASE_KEY = 'COLAR_AQUI_A_CHAVE_PUBLICA';

const supabase = window.supabase.createClient(
    SUPABASE_URL,
    SUPABASE_KEY
);

const formulario = document.getElementById('contato-form');

formulario.addEventListener('submit', async (evento) => {
    evento.preventDefault();

    const dados = {
        nome: document.getElementById('nome').value.trim(),
        email: document.getElementById('email').value.trim(),
        telefone: document.getElementById('telefone').value.trim(),
        mensagem: document.getElementById('mensagem').value.trim()
    };

    if (!dados.nome || !dados.email || !dados.telefone || !dados.mensagem) {
        alert('Preencha todos os campos.');
        return;
    }

    const botao = formulario.querySelector('button[type="submit"]');
    botao.disabled = true;

    const { error } = await supabase
        .from('contatos')
        .insert([dados]);

    if (error) {
        console.error(error);
        alert('Não foi possível enviar a mensagem. Tente novamente.');
    } else {
        formulario.reset();
        alert('Mensagem enviada com sucesso!');
    }

    botao.disabled = false;
});

5. Testar no XAMPP

  1. Inicie o Apache no XAMPP.
  2. Abra http://localhost/Projetos/fale-conosco.html.
  3. Preencha os quatro campos.
  4. Clique em Enviar mensagem.
  5. Abra o Supabase em Table Editor.
  6. Selecione contatos e confira o registro novo.

6. Testar na Vercel

  1. Envie o novo código ao GitHub.
  2. Faça o deploy na Vercel ou aguarde o deploy automático.
  3. Acesse o endereço publicado.
  4. Abra a página Fale Conosco.
  5. Envie uma mensagem de teste.
  6. Confira a mensagem no painel do Supabase.

7. Visualizar os contatos enviados

O painel administrativo pode ler registros com a chave pública porque existe uma política somente para usuários autenticados. A opção mais segura é:

  1. Criar uma página ou painel protegido por login.
  2. Ativar autenticação no Supabase.
  3. Permitir o cadastro ou adicionar usuários no Authentication.
  4. Ler os dados com supabase.auth.getUser() e usar a sessão autenticada.

Também é possível consultar diretamente no Table Editor como dono do projeto, sem usar a chave pública.

Problemas comuns

Erro de política RLS

Confirme que RLS está ativado, que existe a política de inserção para anon e que o usuário recebeu permissão de insert.

Erro de chave ou URL

Verifique se copiou a Project URL e a chave pública corretas, sem aspas ou espaços extras.

Mensagem não aparece no Table Editor

Abra o Console do navegador e confira a mensagem completa do erro. Confirme os nomes dos campos e o nome da tabela.

Erro de CORS

Verifique se o domínio está correto e se o projeto Supabase está ativo. Um erro de URL ou chave normalmente aparece como falha de autenticação, não como problema do HTML.

Boas práticas

  • Valide os dados no navegador e no banco.
  • Limite o tamanho dos campos.
  • Use HTTPS.
  • Ative RLS em todas as tabelas públicas.
  • Não habilite leitura pública de dados pessoais.
  • Nunca publique a chave service_role.
  • Faça backup antes de alterar a estrutura da tabela.
  • Monitore o uso do projeto no painel do Supabase.

Checklist final

  • □ Projeto criado no Supabase.
  • □ Senha do banco armazenada em local seguro.
  • □ Tabela contatos criada.
  • □ RLS ativado.
  • □ Política permite somente inserção pública.
  • □ Leitura restrita a usuários autenticados.
  • □ Project URL e chave pública configuradas no JavaScript.
  • □ Formulário não usa mais contato.php.
  • □ Teste enviado pelo XAMPP.
  • □ Teste enviado pelo endereço da Vercel.
