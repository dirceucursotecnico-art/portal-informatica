Passo a passo: Fale Conosco com PHP e MySQLi

Projeto: Portal do Técnico em Informática – Maria Barbosa Leite
Ambiente: XAMPP, Apache, MySQL/MariaDB e PHP

1. Preparar o XAMPP

  1. Abra o painel de controle do XAMPP.
  2. Clique em Start no Apache.
  3. Clique em Start no MySQL.
  4. Aguarde os dois ficarem verdes.
  5. Acesse http://localhost/Projetos/index.html.

2. Adicionar o botão ao menu principal

Abra index.html. Dentro da área com id="menuLateral", localize o link “Sobre o site” e adicione, logo depois:

<a href="sobre.html">ℹ️ Sobre o site</a>
<a href="fale-conosco.html">💬 Fale Conosco</a>

3. Criar a página HTML do formulário

Crie na pasta do projeto o arquivo fale-conosco.html.

<!DOCTYPE html>
<html lang="pt-BR">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Fale Conosco</title>
    <link rel="stylesheet" href="style.css">
    <link rel="stylesheet" href="contato.css">
</head>
<body>
    <h1>Fale Conosco</h1>

    <form action="contato.php" method="post">
        <label for="nome">Nome:</label>
        <input type="text" id="nome" name="nome" required>

        <label for="email">E-mail:</label>
        <input type="email" id="email" name="email" required>

        <label for="telefone">Telefone:</label>
        <input type="tel" id="telefone" name="telefone" required>

        <label for="mensagem">Dúvida ou reclamação:</label>
        <textarea id="mensagem" name="mensagem" required></textarea>

        <button type="submit">Enviar mensagem</button>
    </form>
</body>
</html>

4. Entender os atributos importantes

  • action="contato.php": indica o arquivo PHP que receberá os dados.
  • method="post": envia os dados pelo corpo da requisição.
  • name="nome", name="email", name="telefone" e name="mensagem": são os nomes usados pelo PHP no $_POST.
  • required: impede o envio vazio pelo navegador.

5. Criar o arquivo PHP

Na mesma pasta, crie contato.php.

<?php
if ($_SERVER['REQUEST_METHOD'] !== 'POST') {
    exit('Acesso inválido.');
}

$nome = trim($_POST['nome'] ?? '');
$email = trim($_POST['email'] ?? '');
$telefone = trim($_POST['telefone'] ?? '');
$mensagem = trim($_POST['mensagem'] ?? '');

if ($nome === '' || $email === '' || $telefone === '' || $mensagem === '') {
    exit('Preencha todos os campos obrigatórios.');
}

if (!filter_var($email, FILTER_VALIDATE_EMAIL)) {
    exit('Informe um e-mail válido.');
}
?>

6. Conectar ao MySQLi

Os dados padrão do XAMPP normalmente são:

$servidor = 'localhost';
$usuario = 'root';
$senha = '';
$banco = 'portal_mbl';

$mysqli = new mysqli($servidor, $usuario, $senha);

if ($mysqli->connect_error) {
    exit('Erro na conexão: ' . $mysqli->connect_error);
}

$mysqli->set_charset('utf8mb4');

7. Criar o banco e a tabela pelo PHP

$mysqli->query(
    "CREATE DATABASE IF NOT EXISTS `$banco`
     CHARACTER SET utf8mb4
     COLLATE utf8mb4_unicode_ci"
);
$mysqli->select_db($banco);

$sqlTabela = "CREATE TABLE IF NOT EXISTS contatos (
    id INT UNSIGNED NOT NULL AUTO_INCREMENT,
    nome VARCHAR(100) NOT NULL,
    email VARCHAR(150) NOT NULL,
    telefone VARCHAR(20) NOT NULL,
    mensagem VARCHAR(1000) NOT NULL,
    data_envio DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    PRIMARY KEY (id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4
  COLLATE=utf8mb4_unicode_ci";

$mysqli->query($sqlTabela);

8. Inserir os dados com segurança

Não coloque os dados diretamente dentro do SQL. Utilize consulta preparada:

$sql = 'INSERT INTO contatos
         (nome, email, telefone, mensagem)
         VALUES (?, ?, ?, ?)';

$stmt = $mysqli->prepare($sql);
$stmt->bind_param('ssss', $nome, $email, $telefone, $mensagem);

if ($stmt->execute()) {
    echo 'Mensagem enviada com sucesso!';
} else {
    echo 'Não foi possível salvar a mensagem.';
}

$stmt->close();
$mysqli->close();
Por que usar bind_param?
Protege contra SQL Injection, pois separa o comando SQL dos dados digitados pelo usuário.

10. Testar o formulário

  1. Inicie Apache e MySQL no XAMPP.
  2. Abra o menu lateral e clique em Fale Conosco.
  3. Preencha nome, e-mail, telefone e mensagem.
  4. Clique em Enviar mensagem.
  5. Acesse o phpMyAdmin em http://localhost/phpmyadmin.
  6. Abra portal_mbl e depois contatos.
  7. Clique em Visualizar para conferir os registros.

11. Corrigir problemas comuns

Erro de conexão

  • Confirme que o MySQL está iniciado no XAMPP.
  • Confirme o usuário root e senha vazia.
  • Se criou senha no MySQL, configure-a em $senha.

Acentuação incorreta

  • Inclua <meta charset="UTF-8"> nas páginas HTML.
  • Use $mysqli->set_charset('utf8mb4');.
  • Use banco e tabela com codificação utf8mb4_unicode_ci.

Página não abre

  • Confirme que os arquivos estão dentro de C:\xampp\htdocs\Projetos.
  • Não abra pelo caminho do VS Code se estiver usando PHP; use o endereço localhost.
  • Confira se o nome dos arquivos corresponde exatamente ao href e ao action.

Resumo dos arquivos

  • index.html: contém o link do menu.
  • fale-conosco.html: contém o formulário.
  • contato.css: estiliza o formulário.
  • contato.php: valida e grava os dados no banco.
  • portal_mbl.contatos: tabela que recebe os registros.
