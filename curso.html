Sobre o Curso

O Curso Técnico em Informática prepara os alunos para conhecer diferentes áreas da tecnologia e desenvolver habilidades para o mercado de trabalho.

Disciplinas do Curso

Informática Básica

Apresenta os conhecimentos fundamentais para utilizar computadores. Inclui sistema operacional, arquivos e pastas, internet, editores de texto, planilhas, apresentações e segurança digital.

Lógica de Programação

Ensina a desenvolver algoritmos para resolver problemas por meio de instruções organizadas. Estuda variáveis, constantes, operadores, entrada e saída de dados, estruturas condicionais, laços de repetição e técnicas para criar programas eficientes.

Arquitetura e Manutenção de Computadores

Ensina como os computadores são organizados e funcionam. Aborda processadores, placas-mãe, memórias, fontes de alimentação, armazenamento e periféricos, além da montagem de computadores e da manutenção preventiva.

Html / Css

Ensina a criar e formatar páginas para a internet. O HTML organiza os conteúdos, como textos, imagens e formulários, enquanto o CSS define a aparência, as cores, as fontes, os espaçamentos e o layout das páginas.

Gestão do Tempo

Apresenta técnicas para organizar tarefas, planejar atividades e cumprir prazos. Ensina a definir prioridades, administrar o tempo e utilizar ferramentas para melhorar a produtividade nos estudos e no trabalho.

Sistemas Operacionais

Estuda os sistemas operacionais, responsáveis por gerenciar os recursos do computador e permitir a execução de programas. Ensina a instalar, configurar e atualizar sistemas, além de realizar manutenção e solucionar problemas de software.

P.O.O. / Java

Ensina a desenvolver programas utilizando Java e os conceitos de programação orientada a objetos. Aborda classes, objetos, atributos, métodos, variáveis, operadores, estruturas condicionais, repetição, herança, encapsulamento e polimorfismo.

Programação Web (JavaScript/PHP/MySQL)

Ensina a desenvolver aplicações para a internet utilizando diferentes tecnologias. O JavaScript permite adicionar interatividade às páginas, o PHP realiza o processamento no servidor e o MySQL armazena e organiza os dados em bancos de dados.

Noções de Robótica

Apresenta os fundamentos da robótica e dos microcontroladores. Estuda sensores, atuadores, componentes mecânicos e plataformas como Arduino, permitindo criar programas que controlam dispositivos eletrônicos e automatizam tarefas.

Redes de Computadores

Ensina como os computadores se conectam e compartilham informações. Aborda topologias de redes, modelos OSI e TCP/IP, cabos, conectores RJ45, equipamentos de rede, acesso à internet, instalação e resolução de problemas de conexão.

Design

Ensina a criar imagens digitais e interfaces visuais para sites e aplicativos. Estuda cores, tipografia, resolução, imagens vetoriais e bitmap, edição de imagens, camadas, composição visual e criação de protótipos de páginas.

Gerenciador de Conteúdo / Banco de Dados

Ensina a criar, personalizar e publicar sites utilizando sistemas de gerenciamento de conteúdo, como o WordPress. Também aborda hospedagem, registro de domínios, acesso a bancos de dados, comandos SQL, backups e restauração de informações.

Programação Web II (PHP/MySQL)

Aprofunda o desenvolvimento de sistemas web com processamento no servidor e armazenamento de dados. Estuda APIs, formulários, sessões, cookies, operações CRUD (criar, consultar, atualizar e excluir dados) e técnicas para proteger aplicações contra ataques, como SQL Injection.

Laboratório de Hardware

Ensina a instalar, desmontar e substituir componentes de computadores com segurança. Aborda o uso de ferramentas, equipamentos de medição, aterramento, normas de segurança e técnicas para identificar e corrigir defeitos físicos nos equipamentos.

Laboratório de Software

Ensina a instalar, atualizar e configurar sistemas operacionais e aplicativos. Trabalha com backup, recuperação de dados, máquinas virtuais, linha de comando, gerenciamento de arquivos, permissões e solução de problemas de software.

Laboratório Web

Tem como foco o desenvolvimento prático de projetos web. Ensina a planejar projetos, definir cronogramas, trabalhar em equipe e integrar linguagens de programação, bancos de dados e ferramentas de desenvolvimento para criar sistemas completos.
