Como publicar seu site gratuitamente na Vercel

Projeto: Portal do Técnico em Informática – Maria Barbosa Leite

Este tutorial ensina a publicar arquivos HTML, CSS, JavaScript e imagens e obter um endereço HTTPS gratuito.
Exemplo: https://nome-do-seu-projeto.vercel.app

Antes de começar

  • Crie uma conta gratuita no GitHub.
  • Crie uma conta gratuita na Vercel, usando o mesmo GitHub.
  • Tenha o projeto organizado em uma pasta.
  • Confirme que a página inicial é um arquivo chamado index.html.
  • Teste o site localmente antes da publicação.

1. Preparar o projeto

  1. Abra a pasta C:\xampp\htdocs\Projetos.
  2. Confirme que o arquivo index.html está dentro da pasta principal.
  3. Organize imagens, CSS e JavaScript em pastas ou mantenha os arquivos na pasta principal.
  4. Verifique links e caminhos relativos. Prefira links como sobre.html e style.css.
  5. Não use caminhos locais do computador, como C:\xampp\htdocs\Projetos, em links ou códigos.
Importante: a Vercel não executa PHP nem fornece MySQL/MariaDB no plano gratuito desse tipo de projeto. Por isso, o formulário contato.php não funcionará diretamente na Vercel. A primeira publicação pode conter apenas o site estático.

2. Criar o repositório no GitHub

  1. Acesse github.com.
  2. Entre em New repository.
  3. Digite um nome, por exemplo portal-informatica.
  4. Escolha Public ou Private.
  5. Clique em Create repository.
  6. Não marque a opção de criar README se não precisar de outros arquivos iniciais.

3. Enviar os arquivos pelo VS Code

Abra o terminal no VS Code e execute os comandos abaixo dentro da pasta do projeto.

git init
git add .
git commit -m "Primeira publicação do site"
git branch -M main
git remote add origin https://github.com/SEU-USUARIO/portal-informatica.git
git push -u origin main

Troque SEU-USUARIO pelo seu nome de usuário do GitHub e confirme que o nome do repositório é igual ao criado.

Se o Git não estiver instalado

  1. Instale o Git em git-scm.com.
  2. Reinicie o VS Code.
  3. Execute novamente os comandos do terminal.
  4. Na primeira autenticação, use o navegador para entrar no GitHub.

4. Criar o projeto na Vercel

  1. Acesse vercel.com.
  2. Clique em Sign Up e escolha continuar com o GitHub.
  3. Autorize o acesso da Vercel à sua conta.
  4. Clique em Add New e depois em Project.
  5. Escolha o repositório portal-informatica.
  6. Clique em Import.
  7. Em Framework Preset, escolha Other para um site HTML puro.
  8. Mantenha Root Directory como ./, caso a pasta não tenha outra pasta principal.
  9. Clique em Deploy.

5. Abrir o site publicado

Após a implantação, a Vercel mostrará uma tela de conclusão. Clique no link semelhante a:

https://portal-informatica.vercel.app

Teste o endereço no celular e no computador. A Vercel adiciona HTTPS automaticamente.

6. Atualizar o site publicado

Para publicar uma alteração, faça o novo envio no VS Code:

git add .
git commit -m "Atualização do site"
git push

A Vercel detectará o envio e fará uma nova implantação automaticamente.

7. Usar um domínio próprio

  1. Abra o projeto na Vercel.
  2. Acesse Settings e depois Domains.
  3. Digite o domínio que deseja usar.
  4. Copie os registros DNS mostrados pela Vercel.
  5. Configure os registros no painel do provedor do domínio.
  6. Aguarde a propagação DNS e clique em verificar quando disponível.

Estrutura recomendada

portal-informatica/
├── index.html
├── style.css
├── script.js
├── sobre.html
├── curso.html
├── projetos.html
├── fale-conosco.html
├── imagens/
└── noticias/
    └── noticias.html

Possíveis problemas

Erro 404 em uma página

Confirme que o nome do arquivo no link é exatamente igual ao nome no repositório. GitHub diferencia maiúsculas de minúsculas.

CSS ou imagens não aparecem

Confira os caminhos. Use style.css para o arquivo na mesma pasta e imagens/foto.jpg para uma pasta chamada imagens.

Formulário não envia mensagens

Arquivos PHP não serão executados na Vercel. Para manter o banco MySQL, utilize uma hospedagem com PHP ou conecte um serviço externo de formulários. Sempre valide dados no servidor e proteja contra injeção SQL.

Git rejeita o envio

Execute git pull --rebase origin main, resolva eventuais conflitos e execute git push novamente.

Checklist final

  • □ index.html está na raiz do projeto.
  • □ Repositório foi enviado ao GitHub.
  • □ Projeto foi importado na Vercel.
  • □ Implantação terminou sem erro.
  • □ Página inicial abre pelo endereço *.vercel.app.
  • □ Links internos foram testados.
  • □ CSS, JavaScript e imagens carregam.
  • □ Site foi testado no celular.
  • □ Atualizações foram enviadas para o GitHub.
