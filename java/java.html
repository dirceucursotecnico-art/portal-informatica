SOBRE O CURSO

Desenvolvimento de Aplicação Java

Como projeto de conclusão do ano, os alunos do 3º ano do Curso Técnico em Informática desenvolveram um sistema utilizando a linguagem de programação Java. O projeto teve como objetivo colocar em prática os conhecimentos adquiridos durante a formação, trabalhando conceitos de programação, organização de código, desenvolvimento de funcionalidades e resolução de problemas.Durante o desenvolvimento, os alunos passaram pelas etapas de planejamento, criação, implementação e testes, transformando os conhecimentos estudados em uma aplicação funcional.

Planejamento

Definição da ideia,

objetivos e funcionalidades do sistema.

Desenvolvimento

Implementação das funcionalidades utilizando Java.

Testes

Verificação do funcionamento do sistema e identificação de possíveis problemas.

Apresentação

Apresentação do projeto e demonstração dos resultados desenvolvidos pelos alunos.
